# DDM model helpers

- `Range`: containment, clamp, normalization, iteration, subdivision, intersection.
- `Vector`: magnitude, normalization, dot/cross, projection, distance, interpolation.
- `Timeline`: time-domain named events.
- `Dataset`: rows/columns, filter/map/group/stats.
- `Size`, `Point`, `Color`: geometry/color convenience types.
- `Matrix`: shape, transpose, arithmetic, matrix/vector multiplication.
- `TreeDDM`: child hierarchy, DFS/BFS walk, find, depth, size.

They integrate with DDM rather than attempting to replace scientific/dataframe libraries.
